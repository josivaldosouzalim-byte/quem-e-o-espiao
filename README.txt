QUEM É O ESPIÃO? — V4

1. Instale Node.js.
2. Abra o terminal nesta pasta.
3. Execute: npm install
4. Execute: npm start
5. Abra http://localhost:3000

V4:
- Perfil com nome e foto.
- Sala multiplayer.
- Palavra secreta diferente para o espião sem avisá-lo.
- Indicador luminoso ao detectar voz local.
- Votação mostra quem já votou e contador.
- Quando todos votam, o jogo aguarda o OK do anfitrião.
- OK da 1ª votação mostra contagem e abre a defesa do mais votado.
- Anfitrião encerra defesa e inicia votação final.
- Após todos votarem novamente, anfitrião autoriza a revelação.
- Resultado mostra contagem, espião e as duas palavras.
- Nova rodada.

OBS.: Para voz entre aparelhos pela internet, será necessário publicar em HTTPS e completar a camada WebRTC/TURN. A detecção visual de voz já está implementada.
